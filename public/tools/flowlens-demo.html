The argument was never wrong. The instruments were. A wrist can now read physiological load every half hour for a month on one charge, know the temperature, and see a calendar. So here is an attempt.

What the defaults say

Flow Opportunity is the only feature that starts off. It is the one thing here that can interrupt someone, and an app about reducing friction that adds friction has argued itself out of existence.

Flow Map starts off too, for a different reason: there is nothing to draw yet. The watch fills its buckets regardless, so the phone view can be switched on later against history that already exists.

Elevated baseline is a number, not a switch. Sixty is a judgement rather than a published figure, and the whole floor turns on it — so it moves from this screen without a rebuild, by someone who knows the occupational health literature better than the source file does.

Turning a parent off takes its sub-features with it whatever their stored value says, and stops the collection rather than merely hiding the screens.

What is actually running

Everything badged running today is built and passing tests: ten pages, a glance, and a separate watch face. The numbers in those frames come from seeded history run through the real analysis, not from a mockup — where a figure looked wrong on the page it was because the analysis said so, and the analysis was usually right.

Meeting Impact is built on the watch but needs a companion phone app to send the calendar, because only watch faces may read calendar complications and there is no other calendar API. The protocol is three numbers per meeting and is written down.

Rush is the only screen here that does not exist. It needs a transit API key and a configured stop, and it is drawn to argue the shape rather than to claim it works.

What the watch can already reach

Meeting Impact needs calendar events and interruption counts. Both are available on-device through the Complications API — no companion app required, which was not what we assumed at the start.

Rush needs more: departure times want a network request and an API key, and a drive-time estimate wants location. Those are the two permissions the manifest does not yet declare.

One promise the platform cannot keep

The obvious version of Underfoot buzzes the wrist the moment you start running on ice. Connect IQ cannot do that. A background process has no access to vibration and wakes every five minutes at best.

So it buzzes when the watch is next looked at, once a day. The only place the immediate version could live is a watch face, which does run continuously — which is a reason to build one, and is said here rather than quietly designed around.

Why it stays observational

Almost everything here is a comparison against your own history, never a population norm and never a clinical reading. “Back toward your weekend baseline on Saturday at 09:30” is a fact about your last eight Saturdays.

The single exception is the floor. Self-reference alone would tell someone whose normal is bad that they are fine, forever — so when the baseline itself sits high on the watch’s own published scale, nothing is allowed to read as simply good, and a screen says why.

The same restraint governs the interruptions. Flow Opportunity is off by default and Rush stays quiet unless it has something true to say, because an app about friction that adds friction has argued itself out of existence.
